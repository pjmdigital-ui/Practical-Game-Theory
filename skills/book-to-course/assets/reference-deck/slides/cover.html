Orientation

The game behind the conversation

Paul Mascetta

Welcome to Internomics. I'm Paul Mascetta. Over the next thirteen weeks I'm going to teach you a different way of looking at communication. This isn't a new set of scripts. It isn't seven phrases to use when someone disagrees with you. It's something underneath all of that. I call it the game behind the conversation. This first module is your orientation. You'll learn what we mean by a game. You'll meet the eleven mental models we'll build together. You'll learn the ethical standard we hold ourselves to. And you'll learn the one loop that runs through everything in this course. Let's start with why this course exists at all.
