A word about language

"Player" is a technical word, not a cynical one.

Internomics · Module 0 — Orientation

Throughout this course I'll use the word "player." That's the correct term in game theory. But I want to be clear: it's a technical word, not a cynical one. The person sitting across from you is not a game piece. They have fears, responsibilities, relationships, beliefs, values, and dignity. If you start treating people as incentives and leverage points, you've learned the wrong lesson. People are always more than players.
