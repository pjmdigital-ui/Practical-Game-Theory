The puzzle

The same approach works with one person and fails completely with another.

Tactics can't explain why. The structure of the interaction can.

Internomics · Module 0 — Orientation

Here's a puzzle you've probably lived. You use an approach with one person and it works beautifully. You use the exact same approach with someone else and it falls flat, or makes things worse. If communication were only about the words, that wouldn't happen. The reason it happens is that each conversation sits inside a different game. Different players, different incentives, different information, different alternatives. Tactics can't explain the difference. The structure of the interaction can.
