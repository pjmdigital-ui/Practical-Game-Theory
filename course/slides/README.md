## Using the decks

- **Recording:** open a deck and use Present mode; the speaker notes show in presenter view.
- **Exporting:** each deck can be downloaded as PowerPoint (.pptx) or PDF from its Share › Export menu, e.g. to record in Keynote, PowerPoint, Loom or Camtasia.
- **Sharing:** the decks are private until you share them from the page's Share menu.

## Structure of every deck

Cover → why it matters → objectives → for each lesson: divider, 2–4 teaching slides, an example, a takeaway → key terms → research spotlight → the module's tool → practice scenario and model answer → common mistakes → field assignment → the question to carry.

## Source files

Each `mNN/project/` folder holds the deck's `deck.json` and one HTML file per slide (`slides/<id>.html`). `STYLE.md` is the shared style guide and `REVISE.md` the writing rules (short sentences, few commas, 180–350 word speaker notes) (palette, type scale, layouts, deck plan) used to build them, so new slides can match.
