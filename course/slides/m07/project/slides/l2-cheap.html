cheap talk (noun)

Costless, nonbinding communication.

Saying it doesn't directly change the material structure of the game. The message costs the sender nothing. It binds no one to anything.

The tempting conclusion: if talk is cheap, talk is meaningless. The research says otherwise.

Internomics · Module 7 — Separate Words From Credibility

Cheap talk sounds dismissive. But technically it has a specific meaning. It's communication that is costless and nonbinding. When I tell you "I'll have it done by Friday" nothing about the world changes. My options and payoffs are the same. Most of what we say every day is cheap talk. So here's the temptation. If talk is cheap then talk must be meaningless. That's the cynic's position. You ask a coworker where the meeting is. It's the right room. So the question isn't whether cheap talk can be informative.
