Internomics · Module 10 — Diagnose the Coordination Problem

Here's a trap. Suppose four roommates all want a clean apartment. Sounds like coordination. But each one thinks: the apartment should be clean, but I'd rather somebody else did the cleaning. That's a different structure. It's a free-rider problem, a public-goods problem. The group shares the goal, but the individual incentive pushes each person toward doing less and hoping others do more. That's a social dilemma. So here's the simple test. Ask yourself: if I knew for certain that everyone else was going to cooperate, would I want to cooperate too? If the honest answer is "yes, absolutely," you're probably dealing with coordination. If the honest answer is "I'd still be better off letting everyone else do the work," you have a social dilemma. And answer it honestly for yourself first.
