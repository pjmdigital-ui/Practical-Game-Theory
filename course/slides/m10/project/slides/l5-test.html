Internomics · Module 10 — Diagnose the Coordination Problem

Here's the most useful question in this module. If I knew for certain that everyone else would cooperate, would I want to cooperate too? The test removes the strategic uncertainty on purpose. If the honest answer is yes it's probably coordination. Clarity and visibility will help. If the answer is "I'd still be better off letting everyone else do the work" you have a social dilemma. Answer it honestly for yourself first. It can be hard to admit you'd happily let someone else clean the kitchen. So what does each answer mean for what you do?
