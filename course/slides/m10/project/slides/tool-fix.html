Internomics · Module 10 — Diagnose the Coordination Problem

Once you've diagnosed the game you choose the intervention. The chapter's menu is a shared plan or a public commitment. A clear owner. A standard. A deadline. A focal point. Or information about what everyone else intends. These work when people are willing but unsure. The five departments needed a shared plan and a deadline. The customer nobody called needed a clear owner. Then write one sentence that makes the next move obvious to everyone. If you can't write it you probably haven't finished diagnosing. Finally run the ethics check. Now let's practice on a real scenario.
