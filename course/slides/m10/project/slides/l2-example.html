Internomics · Module 10 — Diagnose the Coordination Problem

This one can be hard for highly analytical people. Imagine a team choosing a project-management system. System A is slightly better. System B is already used by everyone in the company. Which should they choose? You could spend weeks proving that A has better features. But if half the organization stays on B, you've created a coordination failure. Sometimes a slightly inferior standard used by everyone is more valuable than a superior standard used by half the group. That doesn't mean quality never matters. It means coordination itself has value. Think about language, electrical outlets, file formats, time zones. Much of their value comes from everyone using the same one. Invent an alphabet that's more efficient than English, and if nobody else can read it, the efficiency isn't much use.
