Example · Choosing a system

The better tool, or the one everyone uses?

The situation: A team is choosing a project-management system. System A is slightly better. System B is already used by everyone in the company.

The temptation: Spend weeks proving that A has better features.

What happens: Half the organization stays on B. You've created a coordination failure.

The lesson: A slightly inferior standard used by everyone can beat a superior standard used by half the group.

Internomics · Module 10 — Diagnose the Coordination Problem

A team is choosing a project-management system. System A is slightly better. System B is already used by everyone in the company. You could spend weeks proving A has better features. But if half the organization stays on B you've created a coordination failure. So a slightly inferior standard used by everyone can beat a superior standard used by half the group. This doesn't mean quality never matters. It means coordination has value too. Ask which option is better and which option everyone can reliably land on. Let's put this lesson on one line.
