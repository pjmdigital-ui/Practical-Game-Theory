Example · Five departments

"Every department switches Monday."

The goal: Each prefers the new reporting procedure if all five use it.

The catch: Switching first means extra work, so each one waits.

The move: Management announces it publicly, with a visible migration plan.

The result: The calculation changes. Nobody was persuaded; uncertainty about the others dropped.

Internomics · Module 10 — Diagnose the Coordination Problem

Imagine five departments that all need to switch to a new reporting procedure. Every department prefers the new procedure if all five use it. But switching first imposes extra work, so each one waits for proof that the others are moving. Now management publicly announces: every department switches Monday. And everyone can see the migration plan. The strategic calculation changes. Not because management persuaded anyone that the new system is good. They already believed that. It changes because the uncertainty about what everyone else will do has been reduced. That's coordination. And it's a very different intervention from a pep talk.
