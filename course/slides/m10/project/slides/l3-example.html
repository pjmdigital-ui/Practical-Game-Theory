Example · Five departments

"Every department switches Monday."

The situation: Each department prefers the new reporting procedure if all five use it. Switching first means extra work. So each one waits for proof the others are moving.

What happened: Management announced the date publicly. Everyone could see the migration plan.

What changed: Nobody was persuaded. They already liked the procedure. Uncertainty about the others dropped.

The lesson: A public plan can do what a pep talk can't.

Internomics · Module 10 — Diagnose the Coordination Problem

Five departments need to switch to a new reporting procedure. Each prefers it if all five use it. But switching first imposes extra work. So each waits for proof the others are moving. Then management publicly announces that every department switches Monday and shows the migration plan. The calculation changes. Not because anyone was persuaded. They already believed in it. The uncertainty about everyone else has been reduced. Switching is no longer a lonely bet. When you lead a change do you give people a reason or a shared date? Let's put this on one line.
