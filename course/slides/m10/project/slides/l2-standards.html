Internomics · Module 10 — Diagnose the Coordination Problem

Think about the standards you use every day. Language. Electrical outlets. Time zones. Their value comes partly from everyone using the same one. Imagine an alphabet fifteen percent more efficient than English. If nobody else can read it that efficiency isn't especially useful. Coordination itself has value. Now the caution. Bad conventions can be stable too. "We've always done it this way" may describe a rule that once solved a real problem. It still holds because everyone expects everyone else to keep doing it. So don't confuse stable with good. Now a real choice between two tools.
