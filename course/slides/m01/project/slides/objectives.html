Internomics · Module 1 — See the Game

By the end of this module you'll be able to do five things. You'll define a game the way game theorists do. You'll spot every player who can affect an outcome. You'll separate what someone wants from what they can actually do. You'll map an interaction with the nine questions of the Game Map. And you'll check whether the structure is the problem before you decide someone is. Let's begin with the first shift.
