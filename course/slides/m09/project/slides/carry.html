The question to carry

What changes because there is a next time?

Internomics · Next: Module 10 — Diagnose the Coordination Problem

So here's the question to carry. When you're tempted to maximize the immediate outcome, ask it. What changes because there is a next time? Then ask what you're teaching them to expect from you. Ask whether there's a way to repair the game if something goes wrong. Sometimes the best move today isn't the one that gives you the most today. It's the one that makes tomorrow's game better. And once we start thinking about tomorrow, another problem shows up. Sometimes you and the other person don't want opposing things at all. You'd both be better off acting together. But nobody wants to go first. I'll see you in Module Ten. That's where we learn to diagnose the coordination problem.
