The question to carry

What changes because there is a next time?

Internomics · Next: Module 10 — Diagnose the Coordination Problem

So here's the question to carry. What changes because there is a next time? Ask it when you're tempted to maximize the immediate outcome. Sometimes the best move today is the one that makes tomorrow's game better. But sometimes you'd both be better off acting together and nobody wants to go first. I'll see you in Module Ten. That's where we learn to diagnose the coordination problem.
