The element of surprise

Sometimes changing the pattern is valuable

The manager

Answers every problem with the same solution. Becomes easy to manipulate.

The negotiator

Uses the same concession sequence every time. Can be exploited.

The salesperson

Handles every objection the same way. Becomes predictable.

Not because randomness is powerful.

Because predictability gives the other player information they can use.

Internomics · Module 4 — Manage Predictability

Let's start with the case for surprise. Think about a manager who always responds to every problem with the same solution. People learn what will happen and shape how they present problems to get the answer they want. Or think about a negotiator who always uses the same concession sequence. In each case changing the pattern can be valuable. That's not because randomness is inherently powerful. It's because predictability gives the other player information they can use.
