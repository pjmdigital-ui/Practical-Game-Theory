The pie doesn't have to be fixed

Before asking "Who gets what?", ask "Can we create more value before deciding how to divide it?"

The strategic thinker isn't constantly looking for a winner. They're looking for the structure of the interests.

Internomics · Module 2 — See the Payoffs

Here's an important consequence of seeing mixed interests. If you assume every interaction is zero-sum, you start looking at everything as "Who gets what?" There's a fixed pie, and every slice I take is a slice you lose. But sometimes the better question is, "Can we create more value before deciding how to divide it?" Mixed-motive games are fascinating precisely because they create room for both conflict and cooperation at the same time. That's why the strategic thinker isn't constantly hunting for a winner. They're looking for the structure of the interests: which dimensions we're fighting over, and which ones we could both gain on.
