The pie doesn't have to be fixed

Can we create more value before deciding how to divide it?

The fixed-pie question

"Who gets what?" Every slice I take is a slice you lose.

The better question

Can we make the whole thing worth more first? Then talk about the split.

The strategic thinker isn't looking for a winner. They're looking for the structure of the interests.

Internomics · Module 2 — See the Payoffs

If you assume every interaction is zero-sum, you see everything as one question. Who gets what? There's a fixed pie. But sometimes there's a better question. Can we create more value before deciding how to divide it? The split still matters. It just comes second. This works because people value things differently. If I care a lot about something you care little about, there's room to trade. Both of us end up better off. Fixed-pie thinking assumes we're counting in the same currency.
