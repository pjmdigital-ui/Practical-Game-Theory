The Prisoner's Dilemma: structure, not character

Both cooperate

Both do reasonably well.

One defects

The defector does particularly well. The cooperator suffers.

Both defect

Both do worse than if they'd cooperated.

The players don't have to be bad people. They don't even have to dislike each other. The structure of the payoffs creates the pressure.

Internomics · Module 2 — See the Payoffs

A famous example is the Prisoner's Dilemma. Two people can each cooperate or defect. If both cooperate, both do reasonably well. If one defects while the other cooperates, the defector does particularly well. If both defect, both do worse than they could have by cooperating. Each is tempted to defect. When both do, they both end up worse off. The players don't have to be bad people. The structure of the payoffs creates pressure toward a particular behavior. So before blaming character, ask what the game is rewarding. Can the structure change? It can.
