Key terms

TermPlain-language meaning
PayoffWhat makes an outcome better or worse for a particular player
Payoff functionThe full set of things a person values and how they weigh them
Mixed interestsShared goals on some dimensions. Conflict on others.
Hidden payoffA value such as status or dignity behind the visible stake
Ultimatum GameOne proposes a split. If the other rejects it both get nothing.
Reference pointThe baseline for judging gain or loss. Often an expectation.

Internomics · Module 2 — See the Payoffs

Here are the key terms from this module. A payoff is what makes an outcome better or worse for a particular player. A payoff function is the full set of things a person values and how they weigh them. Mixed interests means shared goals with some conflict. A hidden payoff is a value like status or dignity that drives a decision without being the visible stake. A reference point is the baseline we judge against. And stated versus revealed preference is the gap between what someone says and what their choices show. Now the research.
