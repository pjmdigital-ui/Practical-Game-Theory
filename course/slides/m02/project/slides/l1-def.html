Definition

A payoff is what makes this outcome better or worse for this player.

What they value

In game theory a payoff is what a player values about an outcome.

Numbers optional

Economists use numbers to compare outcomes. You don't need them to use the idea.

Their values

People decide based on what they value. Not on what would make you happy.

Internomics · Module 2 — See the Payoffs

Let's start with the core idea. In game theory a player's payoff is essentially what they value about an outcome. You don't need numbers to use this idea. Here's the working definition. A payoff is what makes this outcome better or worse for this player. People don't make decisions based on what would make you happy. They make decisions based on what they value.
