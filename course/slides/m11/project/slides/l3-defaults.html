The lever that doesn't look like strategy

What happens when nobody chooses is itself a rule.

Continues unless stopped

Every project runs on until someone ends it. Inertia favors continuation.

Expires unless renewed

Every project ends until someone renews it. Inertia favors termination.

Neither rule forces a decision. Both shape what happens when no player acts.

Internomics · Module 11 — Change the Game

Even something as simple as a default can change the strategic environment. What happens when nobody chooses is itself a rule. Imagine every project automatically continues unless someone stops it. Inertia favors continuation. Now imagine every project expires unless someone renews it. Inertia now favors termination. Most players don't act most of the time. So the default quietly decides a huge share of outcomes. People think a default is neutral because it doesn't force anything. It isn't. It decides who has to spend effort to change the outcome.
