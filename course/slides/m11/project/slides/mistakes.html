Common mistakes

Giving another speech

The structure rewards the opposite behavior. Ask what the system actually pays for.

Blaming character first

Ask what the game makes attractive. Structure doesn't explain everything either.

Mistaking the metric for the goal

Ask what behavior moves the number. Then ask what hard-to-measure work loses effort.

Redesigning everything at once

Systems are interconnected. Make the smallest testable change. Then observe.

Internomics · Module 11 — Change the Game

There are eight common mistakes. Mistake one is giving another speech when the structure rewards the opposite behavior. For the sales team the workshop said cooperate. The rankings said compete. The rankings won. Mistake two is blaming character before inspecting the game. But people still have values and still make choices. Mistake three is confusing the metric with the goal. In Kenya scores rose and learning didn't. Mistake four is redesigning everything at once. So start with a diagnosis and make the smallest change that can test it.
