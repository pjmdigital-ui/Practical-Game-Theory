Internomics · Module 11 — Change the Game

This doesn't only apply to governments and companies. It applies at your kitchen table. Imagine a couple who argue about household responsibilities. Every Saturday the same question comes up. Who's doing what? Then conflict. You could work endlessly on tone. You could work on listening and on wording. And those things matter. I've spent a lot of this course on them. But perhaps the deeper solution is this. Stop renegotiating the same game every Saturday. Look at the middle card. They create a system. You handle these responsibilities. I handle those. We rotate this one. And if something unusual comes up, here's how we decide. Now the conflict doesn't fade because both people became better negotiators. It fades because the game changed. There's simply less to fight about each week. Which levers did they pull? Rules, clearly. Who decides, too. They also changed the timing. The negotiation happens once instead of every weekend. Parenting has the same pattern. A child asks for more screen time every evening. The parent says no. The child argues. The parent argues back. Sometimes the parent gives in. The child learns that every night is a bargaining game. A clear rule set in advance changes that. Screen time ends at this time under these conditions with this consequence. No system eliminates every conflict. But the repeated game has changed. Here's a question for you. What argument in your home happens on a schedule? That's a sign it's a game problem.
