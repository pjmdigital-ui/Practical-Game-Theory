Example · Saturday chores

Stop renegotiating the same game

The situation

A couple argues about household jobs every Saturday. "Who's doing what?" Then conflict.

What happened

They create a system. You handle these. I handle those. We rotate this one. Here's how we decide the unusual stuff.

The lesson

Nobody became a better negotiator. The game changed.

Internomics · Module 11 — Change the Game

This applies at your kitchen table. A couple argues about household responsibilities. Every Saturday the same question comes up. You could work endlessly on tone and wording. But the deeper solution may be to stop renegotiating the same game every Saturday. They create a system. You handle these. I handle those. We rotate this one. The conflict doesn't fade because they became better negotiators. It fades because the game changed. They changed the rules and who decides. They changed the timing so the negotiation happens once.
