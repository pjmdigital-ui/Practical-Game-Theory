Internomics · Module 11 — Change the Game

Let's practice. Dana manages a twelve-person software support team. A leaderboard ranks engineers by tickets closed per week. The top three each quarter get a bonus. Dana says customer satisfaction and knowledge-sharing matter most. Yet senior engineers rarely help juniors. Customers keep reopening tickets marked resolved. Reopened tickets are counted as new tickets. Two engineers were caught splitting single issues into several tickets. Dana's boss says fire them and hire people with better values. Don't start with the people. Start with the game. Pause the video now and write your answers down.
