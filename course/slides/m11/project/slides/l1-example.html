Example · The cake

One cuts, the other chooses

The problem

Two children, one cake. Each wants the larger piece, and both complain about any split.

The new rule

One child cuts. The other chooses first. A clearly bigger piece goes to the chooser.

The result

The cutter's self-interest now produces equal pieces. No lecture on fairness needed.

Internomics · Module 11 — Change the Game

Here's a simple example often used to illustrate the idea. Two children need to divide a cake, and each wants the larger piece. A parent could try to divide it perfectly, and both children may still argue, "Their piece is bigger." Or the parent can change the mechanism: one child cuts, the other chooses first. Suddenly the child cutting the cake has every reason to make the pieces as equal as possible. Why? Because if one piece is clearly larger, the other child gets to take it. The parent didn't change the children's personalities. Didn't give a lecture on fairness. Didn't try to make them less selfish. The parent changed the rules so the children's own incentives produced the fair outcome. That's incentive compatibility: the mechanism doesn't fight the preference for the bigger piece, it uses it.
