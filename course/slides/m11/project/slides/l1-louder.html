Internomics · Module 11 — Change the Game

An organization can say "quality matters" but reward volume. It can say "think long-term" but measure only this quarter. It can say "experiment" but punish every failure. It can say "tell us the truth" but retaliate against bad news. It can say "work as a team" but reward people only for individual results. When the stated value and the rewarded behavior conflict, don't be surprised when the reward wins. Now, this doesn't mean incentives explain everything. People have values. People sometimes do what's right even when it costs them. People resist bad incentives. But if you repeatedly create a payoff for a behavior, you shouldn't be shocked when more of that behavior appears.
