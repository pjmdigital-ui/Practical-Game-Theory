Internomics · Module 5 — See the Equilibrium

Here's where things get more interesting. Some games have one equilibrium. Others have several. The same underlying game can support more than one stable pattern. Take two people trying to coordinate. If each person's best response is simply to match the other, then both choosing A is stable, and both choosing B is stable. The problem isn't picking the wrong strategy. The problem is: how do we get to the same one? That's a coordination problem, and it gets its own module later. And it points to a real limitation of the concept. Knowing that a game has two equilibria doesn't tell you which one people will choose. That's called the equilibrium-selection problem. Research following Schelling found that salient labels and cues can help, but that even small differences in payoffs could substantially disrupt coordination around an otherwise obvious choice.
