Internomics · Module 5 — See the Equilibrium

I want you to use this idea with integrity, so here's a credibility rule. Say "Nash equilibrium" when you're talking about a formal game where you've actually specified the strategies and the payoffs. For the everyday patterns in your life, say "equilibrium lens." Your marriage isn't literally in a Nash equilibrium unless you've modeled it. But a pattern can resemble an equilibrium trap, and that's a useful thing to notice. And remember, not everything that persists is an equilibrium. Habit can keep things going. So can coercion, inertia, or a rule nobody questions. So run a simple test: would changing alone actually make this person worse off? If yes, the equilibrium lens fits. If not, something else is holding the pattern in place, and you'll want a different explanation.
