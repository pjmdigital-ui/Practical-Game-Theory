Key terms

TermPlain-language meaning
Nash equilibriumEach choice is a best response to the others. No one has a reason to change alone.
Unilateral changeOne player changes while everyone else keeps doing the same
Prisoner's DilemmaEach player's best response is to defect. Both would prefer cooperating.
Equilibrium trapA stable pattern people dislike but see no good way to leave alone
Self-reinforcing patternEach response provokes the response that sustains it

Internomics · Module 5 — See the Equilibrium

Let's lock in the vocabulary. A Nash equilibrium is a set of strategies where each player's choice is a best response to the others. It says nothing about whether the outcome is good. Unilateral change is one player changing while everyone else stays put. The Prisoner's Dilemma is the classic game where both defect even though both would prefer mutual cooperation. An equilibrium trap is a stable pattern the people inside it dislike. And a self-reinforcing pattern is a loop like complaining and withdrawing.
