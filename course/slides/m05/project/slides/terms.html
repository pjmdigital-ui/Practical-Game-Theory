Internomics · Module 5 — See the Equilibrium

Let's lock in the vocabulary. A Nash equilibrium is a set of strategies where each player's choice is a best response to the others', so no one has a reason to change on their own. Unilateral change is one player changing while everyone else keeps doing what they were doing, and equilibrium is defined by the lack of reward for that. The Prisoner's Dilemma is the classic game where each player's best response is to defect, so both defect, even though both would prefer mutual cooperation. An equilibrium trap is a stable pattern the people inside it dislike but that no one sees a good way to leave alone. And a self-reinforcing pattern is a loop where each person's response provokes the response that keeps it going, like complaining and withdrawing.
